# To-Do List Application

## Описание

To-Do List Application е конзолно Python приложение за управление на задачи.

Проектът е разработен като курсова работа по програмиране за първи курс. Основната му цел е да покаже използването на основни програмни конструкции в Python, включително списъци, речници, цикли, класове, работа с файлове и обработка на грешки.

Приложението позволява на потребителя да създава, преглежда, редактира, изтрива и управлява задачи чрез текстово меню.

---

## Функционалности

Програмата поддържа следните операции:

- Добавяне на нова задача
- Показване на всички задачи
- Маркиране на задача като изпълнена
- Изтриване на задача
- Търсене на задача по ключова дума
- Показване само на изпълнени задачи
- Показване само на неизпълнени задачи
- Сортиране по приоритет
- Сортиране по краен срок
- Редактиране на задача
- Показване на статистика
- Записване на задачите във файл
- Зареждане на задачите от файл
